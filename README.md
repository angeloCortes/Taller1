# El grupo de POO - Sistema de Control de Inscripciones y Gestión de Alumnos

## 1. Descripción del Proyecto
Se debe crear un sistema que sea capaz de filtrar quién entra y quién no al grupo de WhatsApp del ramo de POO, donde también se puede agregar manualmente a los alumnos rezagados y administrar los alumnos y paralelos del grupo usando Java.

El sistema permite cargar nóminas de estudiantes y solicitudes desde archivos de texto, realizar un filtrado y procesamiento automático de postulaciones, efectuar inscripciones manuales, administrar la lista oficial de alumnos (agregar, eliminar o modificar paralelo con persistencia de datos en `Alumnos.txt`), generar reportes por paralelo/rechazados con control de versiones en archivos `.txt`, y visualizar un análisis estadístico sobre el proceso de admisión.
